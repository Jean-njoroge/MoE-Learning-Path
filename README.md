
# 🧩 Mixture of Experts (MoE) Learning Path

Welcome! This repo is a **guided learning path** for understanding, building, and applying **Mixture of Experts (MoE)** models.

## 🎯 Goals
- Understand the foundations (probability, Gaussian distributions, mixture models)
- Learn the core MoE papers (Switch Transformer, GLaM, etc.)
- Explore tutorials and hands-on examples
- See how MoE fits into real-world applications
- Curate resources (papers, blogs, diagrams)

This repository is a **4-week structured learning journey** into Mixture of Experts (MoE) — a powerful architecture that enables scaling large models efficiently.  

It blends **foundational AI concepts**, **hands-on coding exercises**, and **research insights**, so you not only learn *what* MoE is, but also *where it fits* in the broader AI ecosystem.
